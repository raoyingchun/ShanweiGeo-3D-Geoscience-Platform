ShanweiGeo — English Edition (Windows x64)
Date: 21 October 2026

1. Extract the entire ZIP into a writable folder.
2. Run "ShanweiGeo English.exe". Do not run inside the ZIP.
3. No Node.js or Python installation is required. A local Python runtime is included.
4. Start with the synthetic files in "Sample Data" before opening your own data.
5. This edition uses a separate profile: %APPDATA%\ShanweiGeo-English.
6. Your data, document contents, filenames and user-created names are retained in their original language.
7. The standalone legacy COORD application is not included. Its original interface remains in its own language when launched separately.
8. This is a test build. Keep source datasets and project backups.

Language scope: the application interface, menus, dialogs, property panels and built-in notifications are in English. Operating-system dialogs follow Windows language settings. Imported documents and data are not translated.

Offline operation: built-in viewing and local processing run on this computer. Online links or externally configured tools may have separate requirements.
