ShanweiGeo 3D Geoscience Platform — Windows x64
Version 1.0.0 · 2 November 2026

HOW TO RUN
1. Extract the entire ZIP into a writable folder.
2. Run "ShanweiGeo 3D Geoscience Platform.exe". Do not run it from inside the ZIP.
3. No Node.js or Python installation is required. A local Python runtime is included.
4. Start with the sample files in "Sample Data" before opening your own data.
5. This edition uses a separate profile: %APPDATA%\ShanweiGeo-English.
6. Your data, document contents, filenames and user-created names are retained in their original language.
7. The standalone legacy COORD application is not included. Its original interface remains in its own language when launched separately.
8. This is a test build. Keep source datasets and project backups.

LANGUAGE SCOPE
The application interface, menus, dialogs, property panels and built-in notifications are in English. Operating-system dialogs follow Windows language settings. Imported documents and data are not translated.

OFFLINE OPERATION
Built-in viewing and local processing run on this computer. Online links or externally configured tools may have separate requirements.

SCOPE OF THE SOFTWARE
The platform organises exploration data into research regions and provides multiple 3D views, layer controls, side-by-side comparison, dataset registration, imagery drapping, document viewing, project persistence and local processing.

Automated geological modelling and mineral prospectivity prediction are future research objectives. They are not implemented in this release.

THIRD-PARTY DATA
The "Sample Data" folder contains synthetic and demonstration datasets. The simulated tunnel example is explicitly marked as simulated and is not a validated engineering design.
