ShanweiGeo Windows test build (19 October 2026)

1. Startup

For 64-bit Windows 10 and 11 computers. Extract the entire ZIP into an
ordinary local folder and double-click the executable. Do not copy only the
EXE: the resources folder and the accompanying DLLs must be kept alongside it.
Neither Node.js nor Python needs to be installed, and no network access is
required for first use.

2. Starting the test

1. Create a project, then create a deposit, mining area or mine section, or
   accept the default extent.
2. 3D block model: create a category and import "Sample Data/demo-blocks.csv"
   (1,000 blocks, 3 classes).
3. 3D geological model: in the model category, import
   "Sample Data/demo-model.ts".
4. Surface elevation: import "Sample Data/demo-terrain.asc" through the
   elevation entry point.
5. Remote sensing imagery and figure management: import
   "Sample Data/demo-image.tif", double-click to display it, and optionally
   enter registration mode.
6. Report management: import "Sample Data/demo-document.pdf" and test
   opening, text selection, labels and notes.
7. Test whether opening the same file again switches to the existing tab, and
   whether a saved project reopens correctly.

All sample files are synthetic and do not represent a real mining area. You
may import your own data; please confirm that you have the necessary rights
first.

3. Testing boundaries

This package does not include personal projects, mining area data, user
sessions or a personal material library.

The original COORD application is a separate external tool and is not
included in this package. The coordinate conversion entry points need the
original software to be configured separately; the remaining model, figure and
document features do not depend on COORD.

This is an unsigned test build with no automatic update. If your system
blocks it, verify the source of the file and contact the provider.

Large models such as the 670,000-block model still require a suitable
graphics card and sufficient memory; a smoother quality option is available
in the display settings. Never overwrite the only copy of a production
project with this test build.

4. Save locations and feedback

Caches, sessions, notes and logs are stored under %APPDATA%\ShanweiGeo-Test.
The project save location is chosen by you.

When reporting a problem, please provide the steps taken, the expected
result, the actual result, an error screenshot, the Windows version and the
graphics card model; attach the logs from the logs folder of the directory
above when relevant. Logs may contain local file paths, so review them before
sharing.
