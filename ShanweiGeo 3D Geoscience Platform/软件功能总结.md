# 软件功能总结

整理日期：2026年10月19日

## 软件定位

本软件是一套面向矿床、矿区和矿段的本地三维地质资料管理、可视化与对比展示软件。

以“矿床—矿区—矿段”为组织结构，集中管理地质模型、地表高程、遥感影像、钻孔及文档资料，提供多画布展示、区域对比、配准贴合、图层控制和项目保存恢复，支持在本地开展地质资料整理与三维成果展示。

## 已实现的主要功能

| 功能模块 | 已实现内容 |
| --- | --- |
| 研究区域管理 | 矿床→矿区→矿段三级结构；右键新建、重命名、删除；当前区域高亮定位。 |
| 区域资料隔离 | 每个区域拥有独立资料树；从具体条目导入文件；支持移动归属，并同步模型所在画布。 |
| 多三维画布 | 不同区域的模型进入不同标签；各画布独立管理场景、原点和相机；标签与项目树双向定位。 |
| 三维模型显示 | 导入 TS、OBJ、坑道 STR/DTM、CSV 块体等数据；支持旋转、缩放、平移、聚焦和模型选择。 |
| 图层与模型属性 | 显隐、颜色、透明度、顺序调整；点线粗细设置；单击图层查看模型属性。 |
| 区域对比 | 左右分屏、选择对比视图、交换左右、调整分屏宽度；独立或同步操作、同步剖切、两侧图层管理。 |
| 地表高程 | ASC 高程导入、渐变配色、边界零值隐藏、垂直显示比例调整。 |
| 遥感影像与图件 | 图片及 TIFF 预览、控制点配准、带坐标影像显示、遥感影像贴合高程。 |
| 点、线与钻孔资料 | 点数据及线数据导入显示；钻孔相关表格管理；柱状图、岩芯资料和化验数据联动入口。 |
| 文档与表格阅读 | PDF、Word、Excel、CSV 等资料导入与查看；PDF 文字选择；文档书签、笔记等资料管理。 |
| 展示效果 | 柔和光照、哑光材质、背景设置；岩石材质库、自定义纹理及单模型材质参数。 |
| 实用工具 | 坐标转换工具，支持经纬度、高斯平面、空间直角坐标及相关参数配置；另有原 COORD 程序调用入口。 |
| 辅助操作 | 测距、剖切、截图、坐标轴、图例及视角复位。 |
| 项目保存恢复 | 保存区域结构、资料归属、标签、图层、视角和配准等状态；支持现场草稿恢复。 |
| 本地运行与启动优化 | Electron 桌面界面与本地 Python 计算通道；文档库按需加载，非当前画布模型延迟恢复。 |

- 目前重点是资料管理、已有模型展示和交互分析，并非完整的自动地质建模或成矿预测系统。
